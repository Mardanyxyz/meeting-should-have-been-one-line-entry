A single sentence that could have replaced an entire pointless meeting — a decision already made (the logo stays blue, the launch is Tuesday) and the only reason the meeting still exists: so Dave can say he was in the room when it happened. One line, one sentence, 120 characters.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (deterministic, works from any directory).
